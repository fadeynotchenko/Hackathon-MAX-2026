Проведи read-only аудит области: **$ARGUMENTS**

Делегируй чтение и анализ субагенту `maxapp-auditor` (через Agent tool), ограничив его
областью **$ARGUMENTS**. Аудит покрывает:

- **Корректность**: граничные случаи, гонки, идемпотентность (сессии, refresh-ротация,
  события Redis Streams), обработка ошибок, которая глотает сбои.
- **Безопасность**: проверка подписи initData, авторизация (админ по ADMIN_MAX_IDS), IDOR,
  утечки секретов в логи и ответы, CSP/cookie-флаги.
- **Архитектура**: слои core (`pyproject.toml`, `[tool.importlinter]`) и `.dependency-cruiser.cjs`,
  сервисы не импортируют друг друга (только `contracts/`), доступ к БД только через репозитории,
  ORM не выходит из `core.usecases`, env только через `core.config.env`.
- **Качество**: дублирование, мёртвый код, тесты, которых не хватает.

Находки — приоритетным списком (critical / high / medium) с `file:line` и конкретным
исправлением. Только отчёт: код не менять без отдельной просьбы.
