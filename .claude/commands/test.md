---
description: Прогнать тесты (pytest + vitest) и починить падения
argument-hint: '[path | -k expr]  (по умолчанию всё)'
---

Прогони тесты проекта из корня репозитория.

- Без аргументов: `cd core && uv run pytest -q`, затем из корня `npx -y pnpm@12.4.2 test`.
- С аргументом `$ARGUMENTS`: если это путь внутри `core/tests/` или выражение `-k`, прогони
  `cd core && uv run pytest $ARGUMENTS -v --tb=short` (путь относительно `core/`); если путь
  внутри `bot/` или `web/`, прогони `npx -y pnpm@12.4.2 vitest run $ARGUMENTS`.

Сообщи результат честно, с реальным выводом. Если что-то падает, прочитай тест и код,
исправь первопричину (не ослабляй тест) и перезапусти упавшую выборку до зелёного.
Коммит и push только по явной просьбе.
