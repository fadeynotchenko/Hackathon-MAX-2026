# Корневые сертификаты вне стандартных хранилищ

`russian_trusted_root_ca.pem`: «Russian Trusted Root CA» Минцифры. Под ним выпущен
сертификат `*.max.ru`, включая хост Bot API `platform-api2.max.ru`. В хранилищах
Node, Debian и macOS этого корня нет, и без него бот получает
`UNABLE_TO_GET_ISSUER_CERT_LOCALLY`: не принимает апдейты и не отправляет сообщения

## Где подключается

| Где               | Как                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------- |
| `bot/Dockerfile`  | копирует файл в образ и выставляет `NODE_EXTRA_CA_CERTS`                                                |
| `compose.yaml`    | передаёт тот же путь контейнеру бота                                                                    |
| запуск без Docker | скрипт `dev` в `bot/package.json` подставляет `NODE_EXTRA_CA_CERTS=./certs/russian_trusted_root_ca.pem` |

Корень добавляется к системным, а не заменяет их: остальные хосты проверяются как
обычно. Замок `core/tests/repo/test_infra_config.py` следит, что образ бота его
подключает

## Происхождение
